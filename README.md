# Zirui Ma — Academic Homepage

This repository contains the source of Zirui Ma's academic homepage, built with [al-folio](https://github.com/alshedivat/al-folio) and deployed through GitHub Pages.

## Content maintenance

- Profile and biography: `_pages/about.md`
- Published and accepted papers: `_bibliography/papers.bib`
- Public research projects: `_projects/`
- Academic service: `_pages/service.md`

Only publicly listed, published, or formally accepted work should be added to the bibliography.

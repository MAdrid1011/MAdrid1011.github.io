Intelligent Computing Core is a Chisel-based, four-issue out-of-order LoongArch processor. It combines in-order fetch and commit with register renaming, dynamic instruction scheduling, and parallel execution pipelines.

The system extends the processor with matrix/vector execution support and dedicated on-chip memory interfaces for intelligent-computing workloads.
